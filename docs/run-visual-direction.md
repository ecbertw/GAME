# EIXO RUN vNext

This folder is the clean replacement for the previous RUN implementation.

Production rules:
- no reuse of old RUN physics, old level data, old replay data or old renderer;
- no JUMP rig, GLB, IK, bone patches or runtime 3D character;
- fixed-outfit 2D sprite Runner;
- stylized 2.5D Astral world;
- game feel first: 120 Hz deterministic movement, acceleration, braking, skid, variable jump, coyote time, jump buffering and fast restart;
- competitive backend, Echoes, Daily and Passport integration are rebuilt only after the new movement foundation is accepted.

The first milestone is intentionally a Movement Lab. It is not the final Astral 01.
