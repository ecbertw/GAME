# EIXO RUN — Art contract

The approved visual reference is the 2026-09-29 final concept supplied by the project owner.

## Runner
- 2D sprite only. No runtime 3D rig.
- Fixed outfit: white / near-black / EIXO red.
- Black spiky hair with red accents, oversized white/red shoes, compact platformer proportions.
- Required readable states: idle, run, skid, jump start, jump, apex, fall, landing, death and victory.
- Cosmetic expansion is limited to overlays/FX (trail, glow, aura, VIP).

## Astral
- Bright blue celestial sky and a giant pale moon.
- Pink/lilac clouds.
- White/blue celestial ruins, floating islands and waterfalls.
- Green vegetation accents and cyan Astral Shards.
- Platforms must be thick, readable and visually separated from background decoration.
- The visual hierarchy is: simple readable Runner + rich 2.5D world.

The concept is a production target, not a licence to reintroduce JUMP rigging or runtime skeletal animation.
